# API Coverage

This matrix tracks the Laravel Cloud API resources covered by the v1 SDK. `Implemented` means the SDK exposes a runtime service on `LaravelCloudClient`. `Future`, `Deprecated`, and `Experimental docs-only` entries are documented here for planning only and aren't exposed as client properties.

| Resource | Official docs URL | v1 status | Reason | Planned service name | Notes |
| --- | --- | --- | --- | --- | --- |
| Applications | https://cloud.laravel.com/docs/api/applications/list-applications.md | Implemented | Stable application CRUD, avatar, include, and pagination endpoints are part of the initial SDK scope. | `client.applications` | Runtime service is available. |
| Environments | https://cloud.laravel.com/docs/api/environments/list-environments.md | Implemented | Stable environment CRUD, lifecycle, logs, metrics, variables, and edge-cache endpoints are part of the initial SDK scope. | `client.environments` | Runtime service is available. |
| Deployments | https://cloud.laravel.com/docs/api/deployments/list-deployments.md | Implemented | Stable deployment list, create, get, and logs endpoints are part of the initial SDK scope. | `client.deployments` | Runtime service is available. |
| Commands | https://cloud.laravel.com/docs/api/commands/list-commands.md | Implemented | Stable command list, run, and get endpoints are part of the initial SDK scope. | `client.commands` | Runtime service is available. |
| Instances/Managed Queues | https://cloud.laravel.com/docs/api/instances/list-instances.md | Implemented | Stable instance CRUD, sizes, managed queue controls, and failed-job list/retry/delete endpoints are part of the initial SDK scope. | `client.instances` | Runtime service is available. The separate environment-level failed-job detail endpoint below remains docs-only. |
| Object Storage Buckets | https://cloud.laravel.com/docs/api/object-storage-buckets/list-object-storage-buckets.md | Implemented | Stable bucket CRUD endpoints are part of the initial SDK scope. | `client.buckets` | Runtime service is available. `allowed_origins` is deprecated in request types, use `cors_settings.allowed_origins`. |
| Object Storage Keys | https://cloud.laravel.com/docs/api/bucket-keys/list-object-storage-keys.md | Implemented | Stable bucket key CRUD endpoints are part of the initial SDK scope. | `client.buckets.keys` | Runtime service is available under buckets. |
| Database Clusters | https://cloud.laravel.com/docs/api/database-clusters/list-database-clusters.md | Future | Database cluster CRUD, metrics, restore, snapshots, and type discovery need their own service and tests before runtime support. | `client.databaseClusters` | `schemas` is deprecated in cluster relationships and includes, use the `databases` relationship and `/databases/clusters/{database}/databases` endpoints instead. |
| Databases | https://cloud.laravel.com/docs/api/databases/list-databases.md | Future | Cluster-scoped database CRUD is not part of the stable v1 runtime surface yet. | `client.databases` | These are the current cluster-scoped database endpoints, not the deprecated legacy `/databases` endpoints. |
| Database Snapshots | https://cloud.laravel.com/docs/api/database-snapshots/list-database-snapshots.md | Future | Snapshot list, create, get, and delete need a dedicated service design and tests before runtime support. | `client.databaseSnapshots` | Current docs scope snapshots under database clusters. |
| Database Restores | https://cloud.laravel.com/docs/api/database-restores/create-a-database-restore.md | Future | Restore creation needs database-cluster service design and response typing before runtime support. | `client.databaseRestores` | Restore returns the newly created database. |
| Caches | https://cloud.laravel.com/docs/api/caches/list-caches.md | Future | Cache CRUD, metrics, and cache type discovery aren't part of the initial SDK runtime surface. | `client.caches` | Future runtime property must remain absent until implemented. |
| Domains | https://cloud.laravel.com/docs/api/domains/list-domains.md | Future | Domain CRUD and verification require DNS workflow documentation and tests before runtime support. | `client.domains` | Future runtime property must remain absent until implemented. |
| WebSocket Clusters | https://cloud.laravel.com/docs/api/websocket-clusters/list-websocket-clusters.md | Future | WebSocket cluster CRUD and metrics aren't part of the initial SDK runtime surface. | `client.websocketClusters` | Future runtime property must remain absent until implemented. |
| WebSocket Applications | https://cloud.laravel.com/docs/api/websocket-applications/list-websocket-applications.md | Future | WebSocket application CRUD, credentials, and metrics aren't part of the initial SDK runtime surface. | `client.websocketApplications` | No `client.websockets` namespace is exposed. |
| Background Processes | https://cloud.laravel.com/docs/api/background-processes/list-background-processes.md | Future | Background process CRUD is documented but needs service naming and instance relationship tests before runtime support. | `client.backgroundProcesses` | Separate from managed queues on instances. |
| Dedicated Clusters | https://cloud.laravel.com/docs/api/dedicated-clusters/list-dedicated-clusters.md | Future | Dedicated cluster listing is documented but not part of the initial stable service set. | `client.dedicatedClusters` | Read-only endpoint in current docs index. |
| Usage | https://cloud.laravel.com/docs/api/usage/get-usage.md | Future | Billing and usage data need response modeling and auth-scope guidance before runtime support. | `client.usage` | Product usage docs also exist at https://cloud.laravel.com/docs/usage.md. |
| Meta | https://cloud.laravel.com/docs/api/meta/get-organization.md | Future | Organization and region metadata endpoints aren't part of the initial stable runtime surface. | `client.meta` | Includes current organization and cloud region lookup. |
| IPs | https://cloud.laravel.com/docs/api/ips/list-ip-addresses-to-whitelist.md | Future | Whitelist IP lookup is documented but not part of the initial stable service set. | `client.ips` | Read-only endpoint in current docs index. |
| Legacy Databases | https://cloud.laravel.com/docs/api/databases-legacy/list-databases.md | Deprecated | The official docs mark legacy `/databases` endpoints deprecated. | None | Use `/databases/clusters`, `/databases/clusters/{database}`, and cluster-scoped database endpoints instead. No runtime service is planned for legacy endpoints. |
| Preview Environments | https://cloud.laravel.com/docs/preview-environments.md | Experimental docs-only | Preview environments are documented as product behavior, but no stable API resource group is listed in the official API index. | None | Don't treat preview environment automation as implemented runtime support. |
| Environment managed queue failed-job detail | https://cloud.laravel.com/docs/api/queuefailedjob/get-environments-managed-queues-failed-jobs.md | Experimental docs-only | The docs index exposes a separate under-specified failed-job detail page outside the implemented instance failed-job endpoints. | None | Keep this docs-only until parameters, response shape, and relationship to instance failed jobs are clear. |

## Runtime Boundary

The SDK must not expose runtime service properties for future resources until their services are implemented and tested. In particular, `client.databases`, `client.caches`, `client.domains`, and `client.websockets` are intentionally absent.
